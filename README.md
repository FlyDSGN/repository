# RuinMessenger — сайт загрузки

Лендинг RuinMessenger. 3D на three.js — модель iPhone 18 Pro: на первом экране с живым чатом и выбором цвета, в «Возможностях» — закреплённый телефон, экран которого меняется при прокрутке.

Иконки — [Phosphor](https://phosphoricons.com), логотипы Huawei и VK — [Simple Icons](https://simpleicons.org); спрайт собирается из npm-пакетов при сборке (`vite.config.js`).

## Команды

```bash
npm install
npm run dev        # локально
npm run build      # сборка в dist/
npm test           # Playwright: скриншоты 320–1440 px в обеих темах + замер FPS при CPU x8
npm run deploy     # сборка и деплой на Cloudflare Workers (messenger.komaru.space)
```

Для деплоя нужны переменные окружения `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID` — в репозиторий их не класть.

## Как устроена производительность

- 3D грузится отдельным чанком после загрузки страницы; до этого виден статичный макет телефона.
- По одному WebGL-контексту на зону (первый экран и «Возможности»). Канвы лежат в потоке документа
  (или в sticky-блоке), поэтому при скролле 3D не отстаёт от вёрстки.
- Материалы — студийные matcap-текстуры (считаются в Web Worker): одна выборка из текстуры на пиксель.
- Телефон — iPhone 18 Pro в четырёх официальных цветах (Deep Black, Silver, Glacier Blue, Burgundy), переключатель под моделью.
- Шейдеры, текстуры и геометрия загружаются в GPU заранее, в простое (`Engine.prewarm`).
- `Governor` следит за долей медленных кадров: сначала рисует 3D реже, потом снижает разрешение.
  Во время скролла на слабых устройствах 3D анимируется через кадр.
- Зоны вне экрана не рендерятся; вкладка в фоне — цикл стоит. `prefers-reduced-motion` — статичные кадры.
- Отладка: `window.__rm3d` в консоли; `?no3d` — страница без 3D.
